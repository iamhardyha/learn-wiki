# Shelf(서재) 앱 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AI 코딩 에이전트가 생성한 리치 HTML 해설 챕터를 맥북 로컬 `.app`에서 ebook처럼 읽고, 새 챕터가 자동으로 쌓이는 개인 지식 서재를 만든다. **다른 사람이 clone 한 번으로 설치하고 `git pull`로 최신화할 수 있어야 한다.**

**Architecture:** 3층 구조이며 접점은 파일 시스템 하나다. 에이전트 스킬이 `~/Shelf/`에 챕터 HTML을 쓰고 `library.json`을 갱신하면, Swift + WKWebView 네이티브 앱이 FSEvents로 그 폴더를 감시하다 변경을 감지해 웹 UI에 리로드 신호를 보낸다. 스킬과 앱은 서로를 호출하지 않고 **폴더 구조 + library.json 스키마**만 계약으로 공유한다.

**에이전트 중립성:** 앱은 특정 에이전트에 묶이지 않는다. 챕터 생성 규약은 `docs/chapter-contract.md` **한 문서**에만 정의하고(실행 가능한 버전이 `validate.py`), 각 플랫폼 스킬은 그것을 **참조만** 한다. 에이전트를 추가하는 일은 재설계가 아니라 그 플랫폼 형식의 스킬 문서를 한 벌 더 쓰는 일이다.

**배포 방침:** 심사받는 레지스트리에 올리지 않는다. 레포 자체가 배포 채널이며 `clone → ./install.sh`가 설치의 전부다. Homebrew 개인 tap은 v1 안정화 후에 얹는 **선택적 편의 계층**이고, `install.sh`가 그때 formula의 빌드 스크립트가 되므로 버려지는 작업이 없다. 기여자를 받지 않으므로 CONTRIBUTING·PR/이슈 템플릿은 만들지 않는다.

**Tech Stack:** Swift 6.3.2 (Cocoa/WebKit/CoreServices) · 프레임워크 없는 HTML/CSS/JS (ES 모듈) · Python 3.14 표준 라이브러리 · Node 24 `node:test` (테스트 전용)

## Global Constraints

모든 태스크의 요구사항에 아래가 암묵적으로 포함된다.

- **외부 의존성 0.** npm 패키지·pip 패키지를 설치하지 않는다. 테스트도 stdlib(`unittest`)와 Node 내장(`node:test`)만 사용한다. `node_modules/`가 생기면 실패다.
- **UI 프레임워크 없음.** React/Vue/번들러 금지. 순수 HTML/CSS/JS ES 모듈.
- **툴체인 고정값(실측):** macOS 26.4 (arm64) · Swift 6.3.2 · Python 3.14.5 · Node v24.16.0. pytest는 **설치되어 있지 않다** — `unittest`를 쓴다.
- **챕터 HTML은 자립형:** 인라인 `<style>`, 외부 리소스 로드 0개. 단 `<!DOCTYPE>`·`<html>`·`<body>` 태그는 **없다**(기존 자산이 프래그먼트 형식). 검증기가 이를 요구하면 안 된다.
- **라이브러리 위치:** `~/Shelf/` (레포 밖). 환경변수 `SHELF_LIBRARY`로 덮어쓸 수 있다.
- **프라이버시 경계(D6·C7) — 이 계획의 최우선 제약.** 이 레포는 **PUBLIC**이다. 업무 관련 식별자(프로젝트 코드명·사내 도메인·업무 이메일·업무 디렉토리 경로)는 코드·주석·문서·테스트·커밋 메시지 **어디에도** 넣지 않는다.
  - 개인/업무 고유값은 전부 레포 밖 설정으로 뺀다: 서재 내용물은 `~/Shelf`, 책 배치는 `~/.config/shelf/book-layout.json`, 금칙어 목록은 `~/.config/shelf/privacy-patterns.txt`.
  - 원본 챕터 경로 같은 값은 하드코딩하지 않고 **CLI 인자나 환경변수로 받는다.**
  - **모든 커밋 전에 `bash tools/privacy-check.sh`가 통과해야 한다.** 실패하면 커밋하지 않는다.
  - `app/ui/library` 심볼릭 링크와 `.shelf-dev/`는 `.gitignore` 필수.
- **library.json 스키마 버전은 `1` 고정.** 배열 순서 = 읽기 순서.
- **UI 언어는 한국어.**
- **배포 없음:** 코드 서명은 ad-hoc(`codesign -s -`)만. dmg·notarization·자동 업데이트 없음.
- **커밋 단위:** 각 태스크의 마지막 스텝에서 반드시 커밋한다.

````markdown
```
~/Shelf/books/<book-slug>/<chapter-slug>.html
```

slug는 소문자·숫자·하이픈만 쓴다: `[a-z0-9]+(-[a-z0-9]+)*`

## 필수 구조

- `<title>` — 비어 있지 않을 것
- `<h1>` — **정확히 1개**
- `<p class="sub">` — 한 줄 요약
- `<div class="wrap">` — 본문 컨테이너

`<!DOCTYPE>`·`<html>`·`<head>`·`<body>` 태그는 **쓰지 않는다.** 챕터는 iframe에
로드되는 프래그먼트이며, 브라우저가 알아서 문서로 감싼다.

## 자립성

외부에서 바이트를 불러오면 안 된다. `<img>`·`<script>`·`<link>`·`<iframe>`·
`<source>`·`<video>`·`<audio>`·`<embed>`·`<object>`의 `src`/`href`/`data`가
`http://`·`https://`·`//`로 시작하면 실패다.

스타일은 인라인 `<style>`에 넣는다. **본문 참고 링크(`<a href="https://…">`)는 허용된다** —
클릭해서 나가는 것이지 로드하는 것이 아니기 때문이다.

## 테마

라이트/다크를 모두 지원한다. `:root`에 CSS 변수를 정의하고
`@media (prefers-color-scheme: dark)`와 `:root[data-theme="dark"]` /
`:root[data-theme="light"]` 오버라이드를 함께 둔다.

## 다이어그램

인라인 `<svg>`로 그린다. **SVG 안에 HTML 태그를 넣지 말 것** —
`<b>`·`<p>`·`<div>`·`<span>` 등을 넣으면 브라우저가 foreign content 규칙에 따라
도형 밖으로 밀어내며 렌더가 깨진다.

강조는 SVG 정식 요소로 한다:

```html
<text x="0" y="10"><tspan font-weight="700">강조</tspan></text>
```

`<tspan>`·`<text>`·`<title>`·`<desc>`는 SVG 요소이므로 허용된다.
````

```python
"""Shelf 챕터·매니페스트 품질 가드. 표준 라이브러리만 사용한다."""

import re

# SVG 안에 나타나면 안 되는 HTML 전용 태그.
# <tspan>·<text>·<title>·<desc>는 SVG 정식 요소이므로 목록에 없다.
HTML_ONLY_TAGS = (
    "b", "i", "u", "strong", "em", "br", "p", "div", "span", "small", "font",
    "h1", "h2", "h3", "h4", "h5", "h6", "ul", "ol", "li", "table", "tr", "td",
    "th", "code", "pre", "img",
)

# 외부에서 바이트를 로드하는 태그. <a>는 본문 참고 링크이므로 제외한다.
RESOURCE_TAGS = (
    "img", "script", "link", "iframe", "source", "video", "audio", "embed", "object",
)

_SVG_BLOCK = re.compile(r"<svg\b.*?</svg>", re.IGNORECASE | re.DOTALL)
_EXTERNAL = re.compile(
    r"<(" + "|".join(RESOURCE_TAGS) + r")\b[^>]*?\b(?:src|href|data)\s*=\s*[\"'](https?:|//)",
    re.IGNORECASE,
)


def _line_of(text, offset):
    return text.count("\n", 0, offset) + 1


def _check_structure(html):
    errors = []
    if not re.search(r"<title>\s*\S", html, re.IGNORECASE):
        errors.append("구조: <title>이 없거나 비어 있음")
    h1_count = len(re.findall(r"<h1[\s>]", html, re.IGNORECASE))
    if h1_count != 1:
        errors.append(f"구조: <h1>이 {h1_count}개 — 정확히 1개여야 함")
    if not re.search(r"<p[^>]*class=[\"'][^\"']*\bsub\b", html, re.IGNORECASE):
        errors.append('구조: <p class="sub">가 없음')
    if not re.search(r"<div[^>]*class=[\"'][^\"']*\bwrap\b", html, re.IGNORECASE):
        errors.append('구조: <div class="wrap">이 없음')
    return errors


def _check_svg(html):
    errors = []
    for block in _SVG_BLOCK.finditer(html):
        line = _line_of(html, block.start())
        for tag in HTML_ONLY_TAGS:
            if re.search(rf"<{tag}\b", block.group(0), re.IGNORECASE):
                errors.append(
                    f"SVG: {line}행 부근 <svg> 안에 HTML 태그 <{tag}> — "
                    "강조는 <tspan font-weight>를 쓸 것"
                )
    return errors


def _check_self_contained(html):
    errors = []
    for match in _EXTERNAL.finditer(html):
        line = _line_of(html, match.start())
        errors.append(f"자립성: {line}행 <{match.group(1)}>이 외부 리소스를 로드함")
    return errors


def validate_chapter_html(html):
    """챕터 HTML 문자열을 검사해 오류 메시지 리스트를 반환한다. 빈 리스트면 통과."""
    return _check_structure(html) + _check_svg(html) + _check_self_contained(html)
```

```python
_SLUG = re.compile(r"[a-z0-9]+(?:-[a-z0-9]+)*")
_DATE = re.compile(r"\d{4}-\d{2}-\d{2}")


def _is_slug(value):
    return isinstance(value, str) and bool(_SLUG.fullmatch(value))


def _check_chapter(chapter, where, seen):
    errors = []
    if not isinstance(chapter, dict):
        return [f"매니페스트: {where}가 객체가 아님"]
    slug = chapter.get("slug")
    if not _is_slug(slug):
        errors.append(f"매니페스트: {where}.slug 형식 오류 ({slug!r}) — 소문자·숫자·하이픈만")
    elif slug in seen:
        errors.append(f"매니페스트: {where}.slug 중복 ({slug})")
    else:
        seen.add(slug)
    if not chapter.get("title"):
        errors.append(f"매니페스트: {where}.title이 비어 있음")
    if not _DATE.fullmatch(str(chapter.get("added", ""))):
        errors.append(f"매니페스트: {where}.added 날짜 형식 오류 — YYYY-MM-DD")
    return errors


def validate_library(obj):
    """library.json 파싱 결과를 검사해 오류 메시지 리스트를 반환한다."""
    if not isinstance(obj, dict):
        return ["매니페스트: 최상위가 객체가 아님"]

    errors = []
    if obj.get("version") != 1:
        errors.append(f"매니페스트: version이 1이 아님 ({obj.get('version')!r})")
    if not isinstance(obj.get("shelfTitle"), str) or not obj.get("shelfTitle"):
        errors.append("매니페스트: shelfTitle이 비어 있음")

    books = obj.get("books")
    if not isinstance(books, list):
        errors.append("매니페스트: books가 배열이 아님")
        return errors

    seen_books = set()
    for index, book in enumerate(books):
        where = f"books[{index}]"
        if not isinstance(book, dict):
            errors.append(f"매니페스트: {where}가 객체가 아님")
            continue
        slug = book.get("slug")
        if not _is_slug(slug):
            errors.append(f"매니페스트: {where}.slug 형식 오류 ({slug!r}) — 소문자·숫자·하이픈만")
        elif slug in seen_books:
            errors.append(f"매니페스트: {where}.slug 중복 ({slug})")
        else:
            seen_books.add(slug)
        if not book.get("title"):
            errors.append(f"매니페스트: {where}.title이 비어 있음")

        chapters = book.get("chapters")
        if not isinstance(chapters, list):
            errors.append(f"매니페스트: {where}.chapters가 배열이 아님")
            continue
        seen_chapters = set()
        for j, chapter in enumerate(chapters):
            errors += _check_chapter(chapter, f"{where}.chapters[{j}]", seen_chapters)

    return errors
```

```python
"""기존 *-guide.html 자산을 ~/Shelf 라이브러리로 이전한다. 표준 라이브러리만 사용.

책 배치와 원본 경로는 이 파일에 하드코딩하지 않는다 — 개인 서재의 책·챕터 이름이
업무 주제를 드러낼 수 있기 때문이다(C7). 배치는 레포 밖 설정 파일에서 읽고,
원본 경로는 인자로 받는다.
"""

import argparse
import html as html_module
import json
import os
import re
import shutil
import sys
from datetime import date
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[1] / "skills" / "lib"))
import validate  # noqa: E402

DEFAULT_LAYOUT = Path.home() / ".config" / "shelf" / "book-layout.json"

_TITLE = re.compile(r"<title>(.*?)</title>", re.IGNORECASE | re.DOTALL)


def shelf_root():
    return Path(os.environ.get("SHELF_LIBRARY", Path.home() / "Shelf")).expanduser()


def load_layout(path):
    """레포 밖 배치 설정을 읽는다. examples/book-layout.example.json 참고."""
    layout = json.loads(Path(path).expanduser().read_text(encoding="utf-8"))
    if not isinstance(layout.get("books"), list):
        raise ValueError(f"배치 파일에 books 배열이 없습니다: {path}")
    return layout


def slug_of(filename):
    """'iceberg-vs-delta-guide.html' → 'iceberg-vs-delta'"""
    stem = Path(filename).stem
    return stem[: -len("-guide")] if stem.endswith("-guide") else stem


def title_of(html, fallback=""):
    match = _TITLE.search(html)
    if not match or not match.group(1).strip():
        return fallback
    return html_module.unescape(match.group(1).strip())


def book_of(layout, chapter_slug):
    for book in layout["books"]:
        if chapter_slug in book.get("chapters", []):
            return book["slug"]
    return None


def build_manifest(entries, layout, added):
    """entries = [(book_slug, chapter_slug, chapter_title)] → library.json 딕셔너리.

    책 순서·챕터 순서는 layout이 정한다(배열 순서 = 읽기 순서).
    챕터가 하나도 없는 책은 결과에서 제외된다.
    """
    by_book = {}
    for book_slug, chapter_slug, chapter_title in entries:
        by_book.setdefault(book_slug, []).append(
            {"slug": chapter_slug, "title": chapter_title, "added": added}
        )

    books = []
    for book in layout["books"]:
        chapters = by_book.get(book["slug"])
        if not chapters:
            continue
        rank = {slug: i for i, slug in enumerate(book.get("chapters", []))}
        chapters.sort(key=lambda c: rank.get(c["slug"], len(rank)))
        books.append({
            "slug": book["slug"],
            "title": book["title"],
            "emoji": book.get("emoji", ""),
            "chapters": chapters,
        })

    return {
        "version": 1,
        "shelfTitle": layout.get("shelfTitle", "서재"),
        "books": books,
    }


def migrate(source, layout_path=DEFAULT_LAYOUT, dry_run=False):
    source = Path(source).expanduser()
    files = sorted(source.rglob("*-guide.html"))
    if not files:
        print(f"원본을 찾지 못했습니다: {source}", file=sys.stderr)
        return 1

    try:
        layout = load_layout(layout_path)
    except (OSError, ValueError, json.JSONDecodeError) as exc:
        print(f"배치 파일을 읽지 못했습니다 ({layout_path}): {exc}", file=sys.stderr)
        print("  examples/book-layout.example.json을 복사해 만드세요.", file=sys.stderr)
        return 1

    root = shelf_root()
    entries, skipped = [], []
    today = date.today().isoformat()

    for path in files:
        chapter_slug = slug_of(path.name)
        book_slug = book_of(layout, chapter_slug)
        if book_slug is None:
            skipped.append((chapter_slug, "배치 파일에 배정 없음"))
            continue
        text = path.read_text(encoding="utf-8")
        errors = validate.validate_chapter_html(text)
        if errors:
            skipped.append((chapter_slug, "; ".join(errors)))
            continue
        entries.append((book_slug, chapter_slug, title_of(text, fallback=chapter_slug)))
        if not dry_run:
            target = root / "books" / book_slug / f"{chapter_slug}.html"
            target.parent.mkdir(parents=True, exist_ok=True)
            shutil.copy2(path, target)

    manifest = build_manifest(entries, layout, added=today)
    manifest_errors = validate.validate_library(manifest)
    if manifest_errors:
        print("생성된 매니페스트가 스키마를 위반합니다:", file=sys.stderr)
        for error in manifest_errors:
            print("   ", error, file=sys.stderr)
        return 1

    if not dry_run:
        root.mkdir(parents=True, exist_ok=True)
        manifest_path = root / "library.json"
        if manifest_path.exists():
            shutil.copy2(manifest_path, root / "library.json.bak")
        manifest_path.write_text(
            json.dumps(manifest, ensure_ascii=False, indent=2) + "\n", encoding="utf-8"
        )

    prefix = "[dry-run] " if dry_run else ""
    print(f"{prefix}이전 {len(entries)}챕터 / {len(manifest['books'])}권 → {root}")
    for book in manifest["books"]:
        print(f"  {book['emoji']} {book['title']} ({len(book['chapters'])})")
    for slug, reason in skipped:
        print(f"  건너뜀: {slug} — {reason}")
    return 0


if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="기존 챕터를 ~/Shelf 서재로 이전한다.")
    parser.add_argument("source", help="원본 *-guide.html 이 있는 디렉토리")
    parser.add_argument("--layout", default=DEFAULT_LAYOUT, help=f"책 배치 파일 (기본: {DEFAULT_LAYOUT})")
    parser.add_argument("--dry-run", action="store_true", help="파일을 쓰지 않고 결과만 출력")
    ns = parser.parse_args()
    sys.exit(migrate(ns.source, ns.layout, ns.dry_run))
```

```js
/** 라이브러리 루트. 앱에서는 스킴 핸들러가, 개발 중에는 심볼릭 링크가 이 경로를 채운다. */
export const LIBRARY_BASE = "library/";

export function chapterHref(bookSlug, chapterSlug) {
  return `${LIBRARY_BASE}books/${bookSlug}/${chapterSlug}.html`;
}

/** 매니페스트를 읽기 순서(책 → 챕터)의 평탄한 배열로 만든다. */
export function flattenChapters(lib) {
  const out = [];
  for (const book of lib?.books ?? []) {
    for (const chapter of book?.chapters ?? []) {
      out.push({
        id: `${book.slug}/${chapter.slug}`,
        bookSlug: book.slug,
        bookTitle: book.title,
        bookEmoji: book.emoji ?? "",
        slug: chapter.slug,
        title: chapter.title,
        added: chapter.added,
        href: chapterHref(book.slug, chapter.slug),
      });
    }
  }
  return out;
}

export function findChapter(flat, id) {
  return flat.find((chapter) => chapter.id === id) ?? null;
}

/** 읽기 순서상 앞뒤 챕터. 책 경계를 넘어 이어진다. */
export function neighbors(flat, id) {
  const index = flat.findIndex((chapter) => chapter.id === id);
  if (index === -1) return { prev: null, next: null };
  return { prev: flat[index - 1] ?? null, next: flat[index + 1] ?? null };
}
```

```js
const ENTITIES = {
  "&nbsp;": " ", "&amp;": "&", "&lt;": "<", "&gt;": ">", "&quot;": '"', "&#39;": "'",
};

/** 챕터 HTML에서 사람이 읽는 텍스트만 남긴다. 다이어그램(svg) 내부 글자는 검색 대상이 아니다. */
export function htmlToText(html) {
  return html
    .replace(/<(script|style|svg)\b[\s\S]*?<\/\1>/gi, " ")
    .replace(/<!--[\s\S]*?-->/g, " ")
    .replace(/<[^>]+>/g, " ")
    .replace(/&nbsp;|&amp;|&lt;|&gt;|&quot;|&#39;/g, (m) => ENTITIES[m])
    .replace(/\s+/g, " ")
    .trim();
}

/** 대소문자 무시 부분 문자열 검색. 각 히트마다 앞뒤 radius 글자의 스니펫을 만든다. */
export function findMatches(text, query, { limit = 3, radius = 40 } = {}) {
  const needle = query.trim().toLowerCase();
  if (!needle) return [];

  const haystack = text.toLowerCase();
  const hits = [];
  let from = 0;

  while (hits.length < limit) {
    const index = haystack.indexOf(needle, from);
    if (index === -1) break;
    const start = Math.max(0, index - radius);
    const end = Math.min(text.length, index + needle.length + radius);
    hits.push({
      index,
      snippet:
        (start > 0 ? "…" : "") + text.slice(start, end) + (end < text.length ? "…" : ""),
    });
    from = index + needle.length;
  }
  return hits;
}
```

```js
/** 책 → 챕터 트리를 그린다. 클릭은 chapter-select 커스텀 이벤트로 위임한다. */
export function renderTree(container, lib, activeId, missingIds = new Set()) {
  container.replaceChildren();

  for (const book of lib?.books ?? []) {
    const section = document.createElement("section");
    section.className = "book";

    const heading = document.createElement("div");
    heading.className = "book-title";
    heading.textContent = `${book.emoji ?? ""} ${book.title}`.trim();
    section.append(heading);

    for (const chapter of book.chapters ?? []) {
      const id = `${book.slug}/${chapter.slug}`;
      const button = document.createElement("button");
      button.type = "button";
      button.className = "chapter";
      button.dataset.chapterId = id;
      button.textContent = chapter.title;
      if (id === activeId) button.classList.add("active");
      if (missingIds.has(id)) {
        button.classList.add("missing");
        button.title = "파일 없음";
      }
      section.append(button);
    }
    container.append(section);
  }
}

/** 트리 컨테이너 하나에만 리스너를 건다(이벤트 위임). */
export function wireTree(container) {
  container.addEventListener("click", (event) => {
    const button = event.target.closest(".chapter");
    if (!button) return;
    container.dispatchEvent(
      new CustomEvent("chapter-select", {
        bubbles: true,
        detail: { id: button.dataset.chapterId },
      })
    );
  });
}
```

```js
import { LIBRARY_BASE, flattenChapters, findChapter } from "./library.js";
import { renderTree, wireTree } from "./sidebar.js";
import { showChapter, wireNav } from "./viewer.js";

const state = { lib: null, flat: [], activeId: null, missing: new Set() };

export async function loadLibrary() {
  const response = await fetch(`${LIBRARY_BASE}library.json`, { cache: "no-store" });
  if (!response.ok) throw new Error(`library.json을 읽지 못했습니다 (HTTP ${response.status})`);
  return response.json();
}

/** 매니페스트에 있지만 파일이 없는 챕터를 표시용으로 모은다(설계 §7). */
async function detectMissing(flat) {
  const missing = new Set();
  await Promise.all(
    flat.map(async (chapter) => {
      try {
        const response = await fetch(chapter.href, { method: "HEAD", cache: "no-store" });
        if (!response.ok) missing.add(chapter.id);
      } catch {
        missing.add(chapter.id);
      }
    })
  );
  return missing;
}

function select(id) {
  const chapter = findChapter(state.flat, id);
  if (!chapter) return;
  state.activeId = id;
  renderTree(document.getElementById("tree"), state.lib, id, state.missing);
  showChapter(chapter, state.flat);
}

export async function refresh() {
  state.lib = await loadLibrary();
  state.flat = flattenChapters(state.lib);
  state.missing = await detectMissing(state.flat);
  document.getElementById("shelf-title").textContent = state.lib.shelfTitle ?? "서재";

  const wanted = location.hash.slice(1) || state.activeId;
  const target = findChapter(state.flat, wanted) ?? state.flat[0];
  if (target) select(target.id);
  else renderTree(document.getElementById("tree"), state.lib, null, state.missing);
}

async function boot() {
  wireTree(document.getElementById("tree"));
  wireNav(select);
  document.addEventListener("chapter-select", (event) => select(event.detail.id));
  window.addEventListener("shelfChanged", () => refresh().catch(console.error));
  await refresh();
}

boot().catch((error) => {
  console.error(error);
  document.dispatchEvent(new CustomEvent("shelf-error", { detail: { error } }));
});
```

```js
import { htmlToText, findMatches } from "./search.js";

const input = () => document.getElementById("search-input");
const results = () => document.getElementById("search-results");
const tree = () => document.getElementById("tree");

const textCache = new Map(); // chapter.id -> 본문 텍스트

async function chapterText(chapter) {
  if (textCache.has(chapter.id)) return textCache.get(chapter.id);
  const response = await fetch(chapter.href, { cache: "no-store" });
  if (!response.ok) throw new Error(`HTTP ${response.status}`);
  const text = htmlToText(await response.text());
  textCache.set(chapter.id, text);
  return text;
}

async function runSearch(flat, query) {
  const hits = [];
  const skipped = [];
  for (const chapter of flat) {
    try {
      const matches = findMatches(await chapterText(chapter), query, { limit: 2 });
      for (const match of matches) hits.push({ chapter, snippet: match.snippet });
    } catch {
      skipped.push(chapter);
    }
  }
  return { hits, skipped };
}

function render({ hits, skipped }, onPick) {
  const box = results();
  box.replaceChildren();

  if (!hits.length && !skipped.length) {
    const empty = document.createElement("div");
    empty.className = "result-empty";
    empty.textContent = "검색 결과가 없습니다.";
    box.append(empty);
  }

  for (const { chapter, snippet } of hits) {
    const item = document.createElement("div");
    item.className = "result";
    item.tabIndex = 0;

    const title = document.createElement("div");
    title.className = "result-title";
    title.textContent = `${chapter.bookEmoji} ${chapter.title}`.trim();

    const body = document.createElement("div");
    body.className = "result-snippet";
    body.textContent = snippet;

    item.append(title, body);
    item.addEventListener("click", () => onPick(chapter.id));
    box.append(item);
  }

  for (const chapter of skipped) {
    const note = document.createElement("div");
    note.className = "result-skipped";
    note.textContent = `${chapter.title} — 검색 제외됨 (본문을 읽지 못함)`;
    box.append(note);
  }
}

function setSearchMode(on) {
  results().hidden = !on;
  tree().hidden = on;
}

/** 검색 입력을 배선한다. getFlat()은 항상 최신 챕터 목록을 돌려줘야 한다. */
export function wireSearch(getFlat, onPick) {
  let timer = null;
  input().addEventListener("input", () => {
    clearTimeout(timer);
    const query = input().value.trim();
    if (!query) {
      setSearchMode(false);
      return;
    }
    timer = setTimeout(async () => {
      setSearchMode(true);
      render(await runSearch(getFlat(), query), (id) => {
        input().value = "";
        setSearchMode(false);
        onPick(id);
      });
    }, 250);
  });
}

/** 챕터가 바뀌면 캐시를 버린다(자동 갱신 시 호출). */
export function clearSearchCache() {
  textCache.clear();
}
```

```js
const KEY = "shelf-theme";

export function initTheme() {
  const saved = localStorage.getItem(KEY);
  if (saved === "light" || saved === "dark") {
    document.documentElement.setAttribute("data-theme", saved);
  }
  document.getElementById("theme-btn").addEventListener("click", toggleTheme);
}

export function toggleTheme() {
  const root = document.documentElement;
  const current = root.getAttribute("data-theme");
  const prefersDark = matchMedia("(prefers-color-scheme: dark)").matches;
  const next = current ? (current === "dark" ? "light" : "dark") : prefersDark ? "light" : "dark";
  root.setAttribute("data-theme", next);
  localStorage.setItem(KEY, next);
}
```

- [ ] **Step 1: `app/Shelf.swift` 작성**

```swift
import Cocoa
import WebKit

let shelfScheme = "shelf"

/// 라이브러리 루트. 개발·테스트에서는 SHELF_LIBRARY로 바꿀 수 있다.
func shelfLibraryURL() -> URL {
    if let override = ProcessInfo.processInfo.environment["SHELF_LIBRARY"], !override.isEmpty {
        return URL(fileURLWithPath: (override as NSString).expandingTildeInPath)
    }
    return FileManager.default.homeDirectoryForCurrentUser.appendingPathComponent("Shelf")
}

/// 번들 안의 웹 UI 루트. 번들 밖(개발 중 직접 실행)에서는 소스 트리를 쓴다.
func uiResourceURL() -> URL {
    if let resources = Bundle.main.resourceURL {
        let bundled = resources.appendingPathComponent("ui")
        if FileManager.default.fileExists(atPath: bundled.path) { return bundled }
    }
    return URL(fileURLWithPath: FileManager.default.currentDirectoryPath)
        .appendingPathComponent("app/ui")
}

final class ShelfSchemeHandler: NSObject, WKURLSchemeHandler {
    static let mimeTypes: [String: String] = [
        "html": "text/html; charset=utf-8",
        "css": "text/css; charset=utf-8",
        "js": "text/javascript; charset=utf-8",
        "json": "application/json; charset=utf-8",
        "svg": "image/svg+xml",
        "png": "image/png", "jpg": "image/jpeg", "jpeg": "image/jpeg", "gif": "image/gif",
        "woff2": "font/woff2", "ico": "image/x-icon", "txt": "text/plain; charset=utf-8",
    ]

    func webView(_ webView: WKWebView, start task: WKURLSchemeTask) {
        guard let url = task.request.url else {
            task.didFailWithError(URLError(.badURL))
            return
        }

        var relative = url.path
        if relative.hasPrefix("/") { relative.removeFirst() }
        if relative.isEmpty { relative = "index.html" }

        // 경로가 library/ 로 시작하면 개인 서재에서, 아니면 번들 UI에서 읽는다.
        let base: URL
        if relative.hasPrefix("library/") {
            base = shelfLibraryURL()
            relative = String(relative.dropFirst("library/".count))
        } else {
            base = uiResourceURL()
        }

        let root = base.standardizedFileURL
        let target = root.appendingPathComponent(relative).standardizedFileURL

        // 상위 경로 탈출 차단
        guard target.path == root.path || target.path.hasPrefix(root.path + "/") else {
            task.didFailWithError(URLError(.noPermissionsToReadFile))
            return
        }
        guard let data = try? Data(contentsOf: target) else {
            task.didFailWithError(URLError(.fileDoesNotExist))
            return
        }

        let mime = Self.mimeTypes[target.pathExtension.lowercased()] ?? "application/octet-stream"
        let response = HTTPURLResponse(
            url: url,
            statusCode: 200,
            httpVersion: "HTTP/1.1",
            headerFields: ["Content-Type": mime, "Content-Length": "\(data.count)"]
        )!
        task.didReceive(response)
        task.didReceive(data)
        task.didFinish()
    }

    func webView(_ webView: WKWebView, stop task: WKURLSchemeTask) {}
}

final class AppDelegate: NSObject, NSApplicationDelegate {
    var window: NSWindow!
    var webView: WKWebView!

    func applicationDidFinishLaunching(_ notification: Notification) {
        let configuration = WKWebViewConfiguration()
        configuration.setURLSchemeHandler(ShelfSchemeHandler(), forURLScheme: shelfScheme)

        webView = WKWebView(frame: .zero, configuration: configuration)
        webView.setValue(false, forKey: "drawsBackground")

        window = NSWindow(
            contentRect: NSRect(x: 0, y: 0, width: 1180, height: 820),
            styleMask: [.titled, .closable, .miniaturizable, .resizable],
            backing: .buffered,
            defer: false
        )
        window.title = "Shelf — 서재"
        window.minSize = NSSize(width: 820, height: 560)
        window.center()
        window.contentView = webView
        window.makeKeyAndOrderFront(nil)

        try? FileManager.default.createDirectory(
            at: shelfLibraryURL(), withIntermediateDirectories: true
        )
        webView.load(URLRequest(url: URL(string: "\(shelfScheme)://app/index.html")!))
        NSApp.activate(ignoringOtherApps: true)
    }

    func applicationShouldTerminateAfterLastWindowClosed(_ sender: NSApplication) -> Bool { true }
}

let application = NSApplication.shared
let delegate = AppDelegate()
application.delegate = delegate
application.setActivationPolicy(.regular)
application.run()
```

- Produces: `LibraryWatcher(path:handler:)` — FSEvents 재귀 감시 + 400ms 디바운스. 변경 시 웹뷰에 `shelfChanged` 커스텀 이벤트를 디스패치한다(`main.js`가 이미 수신 중).

- [ ] **Step 1: `LibraryWatcher` 추가**

```swift
/// ~/Shelf 를 재귀 감시한다. 저장 한 번에 이벤트가 여러 개 오므로 디바운스한다.
final class LibraryWatcher {
    private var stream: FSEventStreamRef?
    private let handler: () -> Void
    private var pending: DispatchWorkItem?

    init(path: String, handler: @escaping () -> Void) {
        self.handler = handler

        var context = FSEventStreamContext(
            version: 0,
            info: Unmanaged.passUnretained(self).toOpaque(),
            retain: nil, release: nil, copyDescription: nil
        )

        let callback: FSEventStreamCallback = { _, info, _, _, _, _ in
            guard let info else { return }
            Unmanaged<LibraryWatcher>.fromOpaque(info).takeUnretainedValue().schedule()
        }

        stream = FSEventStreamCreate(
            kCFAllocatorDefault,
            callback,
            &context,
            [path] as CFArray,
            FSEventStreamEventId(kFSEventStreamEventIdSinceNow),
            0.2,
            FSEventStreamCreateFlags(
                kFSEventStreamCreateFlagFileEvents | kFSEventStreamCreateFlagNoDefer
            )
        )

        if let stream {
            FSEventStreamSetDispatchQueue(stream, DispatchQueue.main)
            FSEventStreamStart(stream)
        }
    }

    private func schedule() {
        pending?.cancel()
        let work = DispatchWorkItem { [weak self] in self?.handler() }
        pending = work
        DispatchQueue.main.asyncAfter(deadline: .now() + 0.4, execute: work)
    }

    deinit {
        pending?.cancel()
        if let stream {
            FSEventStreamStop(stream)
            FSEventStreamInvalidate(stream)
            FSEventStreamRelease(stream)
        }
    }
}
```

````markdown
**형식은 `docs/chapter-contract.md`를 읽고 그대로 따른다.** 이 문서에 계약을 옮겨 적지 않는다 — 두 곳에 적히면 어긋나기 시작한다. 스킬이 설치된 위치에서 계약 문서를 찾지 못하면, 레포의 `docs/chapter-contract.md`를 읽거나 사용자에게 경로를 묻는다.

slug 규칙: 소문자·숫자·하이픈만 (`[a-z0-9]+(-[a-z0-9]+)*`).

### 4. 가드 통과 후 저장·등록
````

````markdown
## 지원 작업

| 요청 | 동작 |
|---|---|
| 책 생성 | `books` 끝에 `{slug, title, emoji, chapters: []}` 추가. slug는 `[a-z0-9-]`만, 중복 금지 |
| 책 이름·이모지 변경 | `title`/`emoji`만 수정. **slug는 바꾸지 않는다**(폴더명과 묶여 있다) |
| 책 slug 변경 | `books/<옛 slug>` 폴더를 `books/<새 slug>`로 `mv`한 뒤 매니페스트 수정 — 둘 다 해야 한다 |
| 챕터 이동 | 파일을 `books/<새 책>/`로 `mv`하고, 매니페스트에서 옛 책의 배열에서 빼 새 책 배열에 넣는다 |
| 챕터 순서 변경 | 배열 순서만 재배치(배열 순서 = 읽기 순서) |
| 책 순서 변경 | `books` 배열 순서 재배치 |
| 챕터 삭제 | **삭제 전 사용자에게 파일 경로를 보여 주고 확인을 받는다.** 확인 후 파일 `rm` + 매니페스트에서 제거 |
| 책 삭제 | 빈 책만 바로 삭제. 챕터가 있으면 챕터 목록을 보여 주고 확인을 받는다 |

## 정합성 점검

작업 후 아래를 확인하고 어긋나면 보고한다.

- 매니페스트의 모든 챕터에 대응하는 `books/<책>/<챕터>.html`이 존재하는가
- `books/` 아래에 매니페스트에 없는 고아 HTML이 있는가

```bash
python3 - <<'PY'
import json, pathlib
root = pathlib.Path.home() / "Shelf"
lib = json.loads((root / "library.json").read_text(encoding="utf-8"))
listed = {f"{b['slug']}/{c['slug']}" for b in lib["books"] for c in b["chapters"]}
actual = {f"{p.parent.name}/{p.stem}" for p in (root / "books").glob("*/*.html")}
for missing in sorted(listed - actual): print("파일 없음:", missing)
for orphan in sorted(actual - listed): print("미등록 파일:", orphan)
print("정합성 OK" if listed == actual else "불일치 있음")
PY
```

## 하지 않는 것

- 챕터 HTML 내용을 편집하지 않는다.
- 확인 없이 파일을 삭제하지 않는다.
- `~/Shelf` 밖을 건드리지 않는다.
````

```bash
#!/usr/bin/env bash
# shelf — Shelf 서재 CLI
set -euo pipefail

# 레포 위치는 install.sh 가 기록한다. git pull 로 제자리 업데이트되므로
# 레포 경로가 곧 설치 경로다.
HOME_FILE="$HOME/.config/shelf/home"
if [ -n "${SHELF_HOME:-}" ]; then
  :
elif [ -f "$HOME_FILE" ]; then
  SHELF_HOME="$(cat "$HOME_FILE")"
else
  SHELF_HOME="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
fi

LIBRARY="${SHELF_LIBRARY:-$HOME/Shelf}"
SKILL_NAMES=(learn shelf learn-from-session)

usage() {
  cat <<'USAGE'
shelf — Claude Code 연동 로컬 지식 서재

  shelf install-skills   설치된 에이전트를 감지해 스킬을 배치
  shelf open             Shelf.app 실행
  shelf update           git pull 후 재설치 (최신화)
  shelf doctor           설치 상태 점검
USAGE
}

install_for() {   # $1=플랫폼 디렉토리명  $2=대상 스킬 루트
  local platform="$1" target="$2" name
  local source_root="$SHELF_HOME/skills/$platform"
  [ -d "$source_root" ] || return 1
  for name in "${SKILL_NAMES[@]}"; do
    [ -f "$source_root/$name/SKILL.md" ] || continue
    mkdir -p "$target/$name"
    cp "$source_root/$name/SKILL.md" "$target/$name/SKILL.md"
  done
  echo "  ✓ $platform → $target"
}

cmd_install_skills() {
  local found=0
  echo "▸ 에이전트 감지"

  if [ -d "$HOME/.claude" ]; then
    install_for claude-code "$HOME/.claude/skills" && found=1
  fi

  # Codex 경로는 Step 1에서 확인된 값을 넣는다. 확인 전에는 비워 둔다.
  if [ -n "${CODEX_SKILLS_DIR:-}" ] && [ -d "$(dirname "$CODEX_SKILLS_DIR")" ]; then
    install_for codex "$CODEX_SKILLS_DIR" && found=1
  fi

  if [ "$found" -eq 0 ]; then
    echo "  설치된 에이전트를 찾지 못했습니다." >&2
    echo "  수동 설치: skills/<플랫폼>/<이름>/SKILL.md 를 에이전트의 스킬 폴더로 복사하세요." >&2
    return 1
  fi
  echo "✓ 완료. 새 세션에서 /learn 을 써 보세요."
}

cmd_open() {
  if [ -d "/Applications/Shelf.app" ]; then
    open "/Applications/Shelf.app"
  elif [ -d "$SHELF_HOME/app/Shelf.app" ]; then
    open "$SHELF_HOME/app/Shelf.app"
  else
    echo "Shelf.app 이 없습니다 — $SHELF_HOME/install.sh 를 실행하세요." >&2
    return 1
  fi
}

cmd_update() {
  echo "▸ git pull"
  git -C "$SHELF_HOME" pull --ff-only
  echo "▸ 재설치"
  bash "$SHELF_HOME/install.sh"
}

cmd_doctor() {
  echo "SHELF_HOME : $SHELF_HOME"
  echo "라이브러리  : $LIBRARY"
  [ -d "$LIBRARY" ] && echo "  ✓ 존재" || echo "  ✗ 없음"
  [ -f "$LIBRARY/library.json" ] && python3 "$SHELF_HOME/skills/lib/validate.py" "$LIBRARY/library.json" \
    || echo "  library.json 없음 — 앱을 처음 켜면 만들어집니다"
  [ -d "/Applications/Shelf.app" ] && echo "앱        : ✓ /Applications/Shelf.app" || echo "앱        : ✗ 미설치"
  [ -d "$HOME/.claude/skills/learn" ] && echo "Claude Code: ✓ 스킬 설치됨" || echo "Claude Code: ✗ 스킬 없음"
}

case "${1:-}" in
  install-skills) cmd_install_skills ;;
  open)           cmd_open ;;
  update)         cmd_update ;;
  doctor)         cmd_doctor ;;
  ""|-h|--help)   usage ;;
  *)              echo "알 수 없는 명령: $1" >&2; usage; exit 2 ;;
esac
```

```bash
#!/usr/bin/env bash
# Shelf 설치 — 재실행하면 업데이트가 된다.
set -euo pipefail

ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"

echo "▸ 사전 점검"
if ! command -v swiftc >/dev/null 2>&1; then
  echo "✗ swiftc 가 없습니다. Xcode Command Line Tools를 설치하세요:" >&2
  echo "    xcode-select --install" >&2
  exit 1
fi
command -v python3 >/dev/null 2>&1 || { echo "✗ python3 가 필요합니다." >&2; exit 1; }
echo "  ✓ swiftc $(swiftc --version 2>/dev/null | head -1 | sed 's/.*version //;s/ .*//')"

echo "▸ 앱 빌드"
bash "$ROOT/app/build.sh"

echo "▸ /Applications 에 설치"
rm -rf "/Applications/Shelf.app"
cp -R "$ROOT/app/Shelf.app" "/Applications/Shelf.app"

echo "▸ shelf CLI 설치"
mkdir -p "$HOME/.config/shelf"
printf '%s\n' "$ROOT" > "$HOME/.config/shelf/home"
chmod +x "$ROOT/bin/shelf"

# 쓰기 가능한 첫 번째 bin 디렉토리를 고른다. sudo를 요구하지 않는다.
BIN_DIR=""
for candidate in "${SHELF_BIN_DIR:-}" "$HOME/.local/bin" "/usr/local/bin"; do
  [ -n "$candidate" ] || continue
  mkdir -p "$candidate" 2>/dev/null || continue
  [ -w "$candidate" ] && { BIN_DIR="$candidate"; break; }
done

if [ -n "$BIN_DIR" ]; then
  ln -sf "$ROOT/bin/shelf" "$BIN_DIR/shelf"
  echo "  ✓ $BIN_DIR/shelf"
  case ":$PATH:" in
    *":$BIN_DIR:"*) ;;
    *) echo "  ⚠ $BIN_DIR 가 PATH에 없습니다. 셸 설정에 추가하세요:"
       echo "      export PATH=\"$BIN_DIR:\$PATH\"" ;;
  esac
else
  echo "  ⚠ 쓰기 가능한 bin 디렉토리를 찾지 못했습니다. 직접 실행하세요: $ROOT/bin/shelf"
fi

echo "▸ 서재 폴더 준비"
mkdir -p "${SHELF_LIBRARY:-$HOME/Shelf}/books"

cat <<'DONE'

✓ 설치 완료

  다음 단계:
    shelf install-skills   # 에이전트에 스킬 설치
    shelf open             # 앱 실행

  최신화:
    shelf update           # git pull + 재설치
DONE
```

````markdown
macOS 13+ · Xcode Command Line Tools(`xcode-select --install`) · Python 3.9+
**의존성 설치는 없습니다** — npm·pip 패키지를 쓰지 않습니다.

## 설치

```bash
git clone https://github.com/iamhardyha/learn-wiki.git
cd learn-wiki
./install.sh            # 앱 빌드 → /Applications 설치 → shelf CLI 설치
shelf install-skills    # 설치된 에이전트를 감지해 스킬 배치
shelf open              # 실행
```

앱은 **여러분의 맥에서 직접 빌드됩니다.** 그래서 코드 서명이나 Gatekeeper 우회가
필요 없고, 배포되는 바이너리도 없습니다.

## 업데이트

```bash
shelf update            # git pull + 재빌드 + 재설치
```

clone한 폴더가 곧 설치 위치이므로, 폴더를 지우지 마세요.

## 서재 먼저 구경하기

내 챕터가 아직 없다면 예시 서재로 열어 볼 수 있습니다.

```bash
SHELF_LIBRARY="$(pwd)/examples" /Applications/Shelf.app/Contents/MacOS/Shelf
```

## 다른 에이전트에서 쓰기

앱은 특정 에이전트에 묶여 있지 않습니다. 연동 계약은 **폴더 하나**뿐이라
(`~/Shelf` 에 챕터 HTML을 쓰고 `library.json` 을 갱신), 어떤 에이전트든 쓸 수 있습니다.

챕터가 지켜야 할 형식은 [`docs/chapter-contract.md`](docs/chapter-contract.md) 한 문서에만
정의돼 있고, 실행 가능한 버전이 `skills/lib/validate.py` 입니다.

```bash
python3 skills/lib/validate.py <chapter.html>   # 계약 준수 검사
```

새 에이전트를 붙이려면 `skills/<플랫폼>/` 에 그 플랫폼 형식의 스킬 문서를 넣고
`bin/shelf` 의 감지 로직에 한 줄 추가하면 됩니다. 계약을 다시 쓸 필요는 없습니다.

## 서재 구조

```
~/Shelf/
  library.json          # 유일한 인덱스 (배열 순서 = 읽기 순서)
  library.json.bak      # 쓰기 직전 자동 백업
  books/
    <book-slug>/<chapter-slug>.html
```

위치는 `SHELF_LIBRARY` 환경변수로 바꿀 수 있습니다.
````

**확정된 사항 (2026-07-27):**

1. **레포명은 `learn-wiki` 유지** (C6). `claude-shelf`로 바꾸지 않는다.
2. **업무 정보는 레포에서 전량 제외.** 마스킹이 아니라 **구조적 분리**로 처리했다 — 개인·업무 고유값(서재 내용물·책 배치·금칙어 목록·원본 경로)을 전부 레포 밖으로 빼고, `tools/privacy-check.sh`가 커밋 전에 강제한다. 설계 문서의 업무 참조 4곳도 제거 완료.
3. **`build_book.py` 강등은 이 계획에서 제외** (설계 §9). 원본이 업무 디렉토리에 있고 v1 동작에 필요하지 않다. 필요해지면 별도 계획으로 잡는다.
4. **에이전트 중립.** 계약을 `docs/chapter-contract.md` 하나로 뽑아 스킬들이 참조만 하게 했다(Task 2). Claude Code는 Task 15~17, Codex는 Task 18. 플랫폼 감지 설치는 `shelf install-skills`.
5. **배포는 레지스트리 없이.** `clone → ./install.sh`가 설치의 전부이고 `shelf update`가 최신화다(Task 20). Homebrew 개인 tap은 **v1 안정화 후 선택**이며, 심사 대상인 homebrew-core가 아니라 본인 소유 레포 하나를 추가하는 일이다. `install.sh`가 그대로 formula의 빌드 스크립트가 되므로 지금 하는 작업 중 버려지는 것은 없다.
6. **기여자를 받지 않는다.** CONTRIBUTING·PR/이슈 템플릿·기여 가이드는 만들지 않는다.

**Task 18 착수 시 주의:** Codex의 스킬 디렉토리와 파일 형식은 **확인 후 채운다.** 확인에 실패하면 Codex 부분을 건너뛰고 `bin/shelf`를 Claude Code 전용으로 커밋한다 — 추측한 경로는 사용자 환경에서 조용히 실패한다.

**실행 중 유의:**

- 각 태스크의 커밋 스텝은 `bash tools/privacy-check.sh`를 **먼저** 돌린다. 계획서에 명시된 커밋 명령을 그대로 쓰되 이 한 줄을 빠뜨리지 않는다.
- 검증 스텝에서 챕터·책 이름을 터미널에 출력하는 건 무방하지만, **그 이름을 레포 파일에 적지 않는다.** 계획서의 검증 스크립트가 이름을 하드코딩하지 않고 매니페스트에서 프로그램으로 고르는 이유다.
- `~/.config/shelf/privacy-patterns.txt`는 기기마다 다시 만들어야 한다(레포에 없으므로). 다른 기기에서 clone하면 `.privacy-patterns.example`을 복사해 채운다.
